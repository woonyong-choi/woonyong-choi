# 최우녕

C# 프레임워크 개발과 PD를 거쳐, 현재는 백엔드 개발에 집중하고 있습니다. 데이터 저장·동시성, AI 도구, Kubernetes 장애 대응에 관심을 두고 구현·검증·배포를 이어갑니다.

[홈페이지](https://woonyong.com/) · [이력서 · 포트폴리오](https://docs.woonyong.com/resume/) · [기술 기록](https://docs.woonyong.com/)

## 대표 프로젝트

### [ToteDB](https://github.com/woonyong-choi/totedb)

데이터 저장과 작업 등록을 한 트랜잭션으로 처리하는 SQL 데이터베이스입니다. C 저장 엔진과 작업 큐를 구현하고 Python 패키지를 배포했습니다.

[저장 구조와 잠금 규칙](https://github.com/woonyong-choi/totedb/blob/main/docs/architecture.md)

### [k8sSeam](https://github.com/woonyong-choi/k8sSeam)

Kubernetes 장애를 진단하고 변경을 Draft PR로 제안하며, 팀장으로 아키텍처·서비스 계약·이벤트 런타임을 맡았습니다. 검증 범위는 kind 장애 재현과 계약 테스트이며, 실제 PR·배포·회복의 전체 연동은 미검증입니다.

[팀 기여와 개인 후속 작업](https://github.com/woonyong-choi/k8sSeam/blob/main/docs/personal-extension.md)

### [Markdown Notes Agent](https://github.com/woonyong-choi/markdown-notes-agent)

AI가 Markdown 노트를 검색·수정하는 MCP 서버를 구현하고 배포했습니다. 수정안 검토와 원문 재확인을 거쳐 파일별로 반영합니다.

[변경 흐름과 현재 상태](https://github.com/woonyong-choi/markdown-notes-agent#작동-방식)

### [다누리 C# 프레임워크](https://github.com/woonyong-choi/dx_framework)

C++ 엔진 위에 액터 생명주기·코루틴·이벤트 API를 구현해 콘텐츠 개발에 사용했습니다. 전체 실행에는 비공개 DLL이 필요하며, 코루틴은 독립 검사할 수 있습니다.

[구현과 공개 범위](https://github.com/woonyong-choi/dx_framework#기여와-공개-범위)

### [PintOS](https://github.com/woonyong-choi/pintos)

교육용 운영체제 팀 구현에 참여했습니다. 과제 종료 후 MLFQS 스케줄러 완성과 선점 오류 수정을 이어가고 QEMU에서 회귀 검사를 확인했습니다.

[기여 범위](https://github.com/woonyong-choi/pintos/blob/main/docs/contribution.md)
