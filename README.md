# 최우녕

백엔드 개발자 최우녕입니다.

요구사항에서 해결할 문제와 제약을 구체화하고, 구현과 검증으로 연결하는 일을 중요하게 생각합니다. [콘텐츠 개발에서 반복되는 엔진 연동을 공통 API로 정리한 경험](https://github.com/woonyong-choi/dx_framework)이 있습니다.

데이터의 일관성, 동시성, 장애 상황에서의 동작에 집중합니다. [ToteDB](https://github.com/woonyong-choi/totedb)에서 저장 구조와 트랜잭션을 구현했고, 팀 프로젝트인 [k8sSeam](https://github.com/woonyong-choi/k8sSeam)에서는 팀장으로 서비스 간 계약과 장애 진단 흐름을 설계했습니다. [PintOS](https://github.com/woonyong-choi/pintos)는 팀 과제 이후에도 스케줄러 결함을 추적하고 보완했습니다.

현재는 AI 도구에도 관심을 두고, 개발 과정에서 얻은 내용을 [블로그](https://woonyong.com/)에 기록합니다.
