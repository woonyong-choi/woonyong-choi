# Asset sources

- `wordmark-*.svg` and `button-*.svg` are native SVG typography and UI assets for this profile.
- `obsidian-official.svg` is the unchanged logo from [Obsidian](https://obsidian.md/images/obsidian-logo-gradient.svg). [Brand guidelines](https://obsidian.md/brand) apply. Its use identifies compatible tools.
- `character-v1.png` and `character-dark-v1.png` are retained earlier character illustrations.
- `woonyong-caricature.png` is the user-selected black-and-white caricature, with the background removed and a white outer edge added. It is used here with the user's permission.
- `cards/*.svg` are native SVG project cards and line icons. Each card has light and dark variants with matching dimensions.
